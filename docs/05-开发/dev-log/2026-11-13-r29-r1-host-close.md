  - 每个窗口增加 pump/loop 分离：事件读取在 pump，所有后端调用
    `Perform/Invalidate` 由该窗 loop 串行执行；R27 首个 Event 返回后才
    标记 `driverReady`；提前 Close/ExitAll 只排队（CAS + 缓冲信号），
    就绪后由 `flushClose` 至多一次交付。

    双门闩：首次或随后已进入 DestroyEvent，Close 不排队、flushClose 不交付。
  - 连续/并发 Close 由 closePending/closeDelivered 两个 CAS 保证一次交付。
  - **进程级 Gio Main**：包级 `gioMain`（owner/calls/Once，不再是每 Host
    一份 Once）与 `ErrGioMainAlreadyOwned`；`WindowHost.Run() error`，
    第二个 Host 或旧单窗入口已调用 Main 时明确拒绝，不重复调用、不扩大
    退出政策。生产 Main 永不返回，`Host.Wait()` 由调用方在另一 goroutine
    观察窗口收口，两者互不代替。旧 Run/RunWith/RunWindow*/单窗进程入口
    API 与行为不变（只包一层 mainFunc 计数）。
