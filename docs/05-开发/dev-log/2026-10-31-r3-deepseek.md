## 切片1（commit `c370028`）— 包加载失败的可定位输入定位（R2-qcode-09）
- 缺陷：`load()` 只取 `p.Errors[0].Msg`，丢弃位置。实测 go/packages 的 `Error.Pos` 在语法/类型错误下**常为空**，真正位置内嵌在 `Msg`（编译器格式 `file:line:col: msg`）。
- 修复：新增 `load_diagnostic.go` 的 `PackageLoadError`：优先 `Error.Pos`，空则由 `Msg` 的 `*.go:line[:col]:` 令牌解析；相对路径按 module root 解析为绝对；**不按冒号首段切分**（正确处理 Windows 盘符/空格/Unicode/行列）；无可靠位置时 `HasPos=false` 且**不伪造**，保留包路径与原因；ROOT-002 码与 GXML span 不变。
- 回归：真实临时 module（目录名含空格+Unicode）复现语法错/类型错/缺包/未知 VM；断言错误对象 `*PackageLoadError` 与真实 `File/Line/Col`，缺包不伪造位置。
- 判别红：overlay 还原只取 Msg → 定位断言 FAIL。
