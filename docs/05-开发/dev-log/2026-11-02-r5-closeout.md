## 审核中补齐的真实缺口

1. A原A3仅记录分配日志；最终使用AllocsPerRun的失败断言，并以可编译的热路径逃逸分配变异证明行为红，再恢复为绿。原“找不到测试是缓存问题”无足够原件支持；go list实际能选中同名测试，不能据猜测删掉验收项。Button/Input真实router事件链、两实例与提交边界独立验证。
2. B原unsafe哨兵稳定，只将error标记不可靠不足以禁止复用；独立真实CLI证实外部local replace依赖改坏仍假命中。最终对不能完整追踪的外部/链接/截断等依赖禁复用，回到正常Analyzer；普通本模块依赖仍真命中。有效上下文从真实go env取得，包含GOENV持久化值，按工程目录观测、有界超时，失败不猜值。
3. clean多删除cause与随后read/stat失败必须一起保留；已完成deleted/skipped不能因后续失败丢失，pending用路径集合而不是带原因文本。用户接管、存活源争议继续拒删，失败不伪称全恢复。
4. C删除后旧坐标可能失效，流程按当前状态重新测量。Dirty两态均含“未保存”，以完整文案/布尔值判别；旧子串不能证明两态。ToUpper是幂等函数，却仍能造成editor/model分歧，文档已改正，不能以“处理器幂等”作为充分同步保证。
