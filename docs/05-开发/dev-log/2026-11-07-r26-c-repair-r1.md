## 修复（最小产品缺口）

1. F-C1：`pipeline.Config` 补 `AssetOutputPaths`（复用既有 owned/本批输出
   优先集合，不另造资产或所有权语义）。真实 owned 冲突在写宿主前由
   `CODEGEN-ASSET-002` fail-closed；未证明所有权的同名文件不误拒。
2. F-C2：`MkdirTemp` 后先写所有权标记，随即把 `HostDir/token` 写回
   `Result`；标记之后所有失败阶段的错误都带证据目录/token，`Run` 置
   `KeptForEvidence`。标记写入失败则安全清理刚创建的空目录；创建目录前
   的失败不留孤儿。`token` 不符不删除的原判据不变。
3. F-C3：单一 `cmd.Wait` goroutine + done 广播；`taskkill` 按
   SystemRoot/WINDIR/SystemDrive 绝对路径解析并带命令时限；终止失败由
   `Stop` 返回并保留在 `StopError()`，`Wait` 错误链保留该失败；回收全部
   有界并对精确自有 PID 兜底 `Kill`。新增 `WaitContext` /
   `ErrHostCanceled` / `ExitError` / `StopError`；`Wait` 既有返回契约未变。
