## For/If 的行事件作用域

修复前，合法的行内 Else、布尔取反条件、索引事件参数及索引 Key 均可通过
前端及 Generate，却在实际 Go 构建时报 `undefined: item` / `undefined: i`。
轮询生成器此前对完整表达式做文本前缀替换，无法处理 `!(item.Done)`，
也没有为 Index 建立轮询变量。仅按索引访问行状态时还会生成未使用的 Each 变量。

现在直接从 Analyzer 的 ResolvedPath 在目标作用域渲染根变量，字段、方法、
取反及事件字面量保持结构语义；Key、事件 Mapping 和分支守卫共用这条路径。
轮询和清理都声明索引变量，渲染侧扫描 If 分支并计入索引 Key，允许循环变量
仅在事件/Key 中使用。

新增 `TestForRowScopeGeneratedCode`：四个真实 GXML 场景两次生成逐字节相同，
生成代码经 Go 工具链构建后，使用 input.Router 合成点击确认分支、行 ID 和
第二行索引正确。测试只调用 Layout 与输入路由，不创建原生窗口或 GPU 上下文。

## 事件字符串中的逗号

修复前 `Click="RecordText('hello, world')"` 被直接按逗号切分，错误报告
`GXML-EVENT-005`。现在在字符串边界之外切分实参，保留单引号内部原始字节，
包括既有的内部撇号与反斜杠；不新增字符串转义语法。

新增 Expander 字面量/混合实参与错误回归；生成代码回归验证逗号、类似循环路径
的文本、XML 解码的双引号/换行和反斜杠完整传到点击处理器。畸形字符串与空参数
经真实 Pipeline 停在 Expander，类型加载与 Codegen 调用次数均为零，原文件不变。
