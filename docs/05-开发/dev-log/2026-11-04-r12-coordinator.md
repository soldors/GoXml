# R12 组合收口

## 接纳范围

- DeepSeek `ec1f601`。将生成器输出修订纳入缓存 K4。保留 GXML 语言版本 1、保护头、Manifest 语义和缓存格式 v7。输出字节规则变化时提升输出修订。组合补强缓存记录逐字节保留断言。
- ZCode `5ecd4f6`。跨包 ViewModel 的默认别名取类型声明包。独立复核复现了五类命名冲突，组合修复复用 Analyzer 已加载的声明包名及命名预检所得目标包声明，不额外查询 VM 目录。类型别名取声明别名的包，保留同包无自导入与确定性消歧。
- WorkBuddy `f1a19d1`。一键工程报告区分检查失败与入口构建失败。组合修复按原生检查标记与真实退出码归因，验收报告使用独占路径，空用例、跳过及已有报告均不能产生通过结论。

## 组合提交

`dd8a840`、`3c32e45`、`301c04d`、`ed9a8cd`、`c4107df`、`3d268ac` 为冻结提交的组合映射。`8757081` 补缓存断言。`80bd37a`、`59ec0a5` 补失败取证与全命中失败对照。`c4add70` 补真实包名及命名冲突。

## 独立反例

只修改目标包用户 Go 文件导入的依赖，且该依赖位于 ViewModel 闭包之外。原生 CLI 仍全命中，`--check` 以 rc=2 拒绝提交；生成物、Manifest 和缓存的 SHA-256 及 mtime 不变。此结果限定了 R12-C 作者对全命中失败场景的判断。
