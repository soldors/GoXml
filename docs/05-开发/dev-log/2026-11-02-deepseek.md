## 片1（commit `2e30b1b`）：--out-dir 目标包名

### 真实复现（先复现后修）
源包 `a`（`src/a.go`=package a）静态页 `--out-dir out`（`out/b.go`=package b，目标已初始化不同包名）：
基线 CLI 生成 `out/home_gen.go` 为 **`package a`**（错），`go build ./out` 失败 `found packages b (b.go) and a (home_gen.go)`（`raw/repro-baseline.json`）。
根因：`resolveInput` 用 `packageDirName(in.sourceDir)` 定包名（`resolvedInput.pkgName` 注释亦写“从源目录解析”），输出契约 §3.2/§4.1 要求包名来自**目标包**。

### 修复
`internal/cli/cache_wire.go resolveInput`：包名改为**目标目录**解析。
- 无 `--out-dir`：targetDir==sourceDir，等价既有。
- 有 `--out-dir` 且目标目录**已初始化**：取目标目录包名 → 静态页搬进不同包时落 `package <目标>`，`go build` 通过。
- 有 `--out-dir` 但目标**不存在/为空**（首建新目录）：**保留既有兼容行为**回退源包名（`isUndeterminableBecauseUninitialized` 区分“未初始化”与“多包”）；这是既有 `TestGenerateCreatesOutDirOnSuccess` 守住的边界，不凭规范删旧回归。
- 目标目录**多生产 package** → 写盘前 fail-closed。
- 同包 ViewModel 解析仍由 `Config.SourceDir` 承担。

### 验证（真实 CLI `cli/goxml-fixed.exe`，`raw/slice1-verify.json`）
静态跨包 `pkg=b` 且 build rc0；空目标兼容回退 `a` 且 build rc0；多包 rc2 无产物；同目录 `pkg=a` build rc0。
Go 回归 `internal/cli/outdir_pkgname_test.go` 4/4；`go test ./internal/cli` ok；vet rc0。

## 片2（commit `bcd416c`）：VM 跨包类型引用

### 真实复现
源同包 VM（`ViewModel="VM"`，VM 在 `src` 包）`--out-dir out`（`out`=package ui）：基线 CLI 生成物用裸 `*VM`、**无 src import** → `go build ./out` 失败 `undefined: VM`（`raw/repro-vm-crosspkg.json`）。
根因：`codegen.vmTypeExpr` 把 `vmRef.PkgDir==""`（同包声明）当“与**产物**同包”，未计入 `--out-dir` 迁移后产物包 ≠ 源包。

### 修复（内部最小，Codegen 不读盘）
- `codegen.Options` 新增内部字段 `ViewModelPackageDir` / `OutputPackageDir` / `ViewModelPackageName`（均由调用方填入，Codegen 不读盘、不加载包、不改公开构造函数形态）。
- `vmTypeExpr`：VM 实际包目录 = 显式 `PkgDir` 或（同包时）`ViewModelPackageDir`；若 ≠ 产物包目录 → 跨包 import。限定符优先用调用方提供的**真实包名** `ViewModelPackageName`（目录名不保证合法标识符，如含 `-`），缺失时回退目录名（仅当合法标识符，否则明确报错）。
- import 一律**强制显式别名**（`alias "import/path"`），使限定符与绑定一致，兼容“包名≠目录名”。
- `internal/compiler/pipeline/pipeline.go`：`Config` 增 `OutputDir`、`ViewModelPackageName`；`RunPrepared` 用 `relToModule` 算两 rel 传给 Codegen。
- `internal/cli/pipeline.go`：两处 `pipeline.Config` 填 `OutputDir=r.targetDir`、`ViewModelPackageName=r.srcPkgName`；`resolveInput` 计算 `srcPkgName=packageDirName(sourceDir)`（纯静态页无 VM 时忽略）。

### 验证（真实 CLI，`raw/slice2-verify.json`、`raw/slice2-extra.json`）
- 同源 VM 跨包：`ui` 包 import `src`、build rc0 ✅
- 目标回 VM 包：`app` 无自导入、build rc0 ✅
- 显式跨包 VM：`z` 包 import `model`、build rc0 ✅
- 别名+包名≠目录名（目录 `vmdir`、包 `otherpkg`）：强制别名 `vmdir "…/vmdir"`、build rc0 ✅
- 绑定失败保旧：非法绑定 rc2、旧 `home_gen.go` 与 Manifest 字节不变 ✅
Go 回归 `internal/compiler/codegen/vm_crosspkg_test.go` 5/5；`codegen` 全包（排除 `TestButtonInRealWindowRuns`）ok；`pipeline` ok；`cli` 全包 ok；三包 vet rc0。
