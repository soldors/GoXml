# R28-B DataGrid 键盘导航语义裁决

日期：2026-11-10

## 范围

本轮仅把 R28-B 已冻结的 DataGrid 键盘候选整理为正式可审查语义，不修改生产 Go 代码，不改变默认行为，不扩大到编辑、多选、排序/过滤、横向滚动或 Tab 焦点环。

组合基线：`474dfb2a047ab19bc56a6093b13c32f7a0bbd204`
实现证据：`7e69a367a51cb40dbe5aef4e11931e7696c908d6`

## 决定

- 批准 C-DG10..C-DG16 的基础语义：显式 opt-in、默认关闭、稳定 RowID 单选、六个纵向导航键、PageRows 缺省口径、空 body 语义、Editor 焦点隔离和不伪造 Clicked。
- 保留两层焦点隔离：Focus 限定过滤器 + 持焦轮询门。
- 通过 ADR-0017、README、任务卡和详细语义表同步状态。
- 原生键盘连发、IME、DPI 与发布级窗口验收仍为未完成门槛。

## 验证

本轮未改 Go 文件；相关 DataGrid 实现、离屏矩阵、race、CGO=0 build、vet、gofmt、docgate、diagdoc 由 R28-B 冻结证据承载。当前线仅复核文档与基线，不重新宣称原生验收通过。

## 发布边界

协调者仍需在原生授权环境中记录真实键盘连发、键位映射、IME、DPI 和窗口关闭结果；在该记录完成前，发布状态应保持“语义已批准、原生验收待完成”。
