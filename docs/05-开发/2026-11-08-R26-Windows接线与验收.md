## 公共命令

```powershell
goxml watch C:/work/my-module --entry ./cmd/app
goxml watch C:/work/my-module --entry ./cmd/app --exclude-dir logs -- --example-arg
goxml preview C:/work/my-module/view/static.gxml --build-only
goxml preview C:/work/my-module/view/static.gxml --tool-root C:/work/Goxml
```

Watch 必须显式指定模块内的 main 包。默认 50ms 轮询、固定 100ms 防抖、每代
generate 与 build 合计 120s 上限；可用 `--poll-ms`、`--build-timeout-seconds`
调整，目录排除可重复。每代调用当前工具 exe 执行真实 `generate --check`，再构建
唯一代次 exe。构建成功前保留旧进程；成功后先停旧树再起新代。新代启动失败不保证
回滚，状态重置，无 Hydration。只扫描模块内普通文件，不承诺模块外依赖监听。

Ctrl+C 取消构建/监听并清理自有树。工具取消有独立有界清理宽限，清理错误显式上报。
模块内运行日志等输出应放在 `.goxml` 或用 `--exclude-dir` 排除，避免输出反过来触发重建。

Preview 仅支持模块内无 VM 的纯静态页，复用已批准的布局、Def/Slot、Image、Expanded
基础范围。VM、绑定/事件、ThemeRef、Button/Input 拒绝，不用伪造 VM 降级。
`--build-only` 只验证构建，不打开窗口；默认命令会启动专用窗口。
`--keep-host-dir` 保留成功宿主，失败总保留证据。构建上限默认 300s，可用
`--build-timeout-seconds` 调整。需要匹配的 goxml 源码/模块缓存根及本地依赖；自动定位
失败（例如 trimpath 安装形态）时显式传 `--tool-root`，不承诺任意单 exe 离线安装。

宿主不导入用户业务包，不执行用户 main/init，不改用户生成物、Manifest、成功缓存。
Manifest 损坏先拒绝；资产按有效 overlay 字节校验/复制，已证明所有权的生成输出不能
通过伪装为图片绕过门禁。临时目录清理核对一次性 token。

## 组件范围

`pkg/widgets` 提供 ContextMenu 与 Modal，调用方保证同时只有一个活动弹层，并在背景
之后布局。菜单有固定条目、视口钳制、禁用项、外点/Escape 关闭和高菜单滚轮访问；
无可视滚动条。Modal 遮罩点击只报告，不默认关闭；Escape 关闭，关闭后的下一次 Layout
回交 ReturnFocusTo。打开转换只请求一次焦点，重复 Open 不抢内容焦点。全捕获键盘
消费者可能先吃 Escape，调用方须按名消费或转发。没有全局弹层仲裁、DataGrid 或 GXML 新标签。

## 已取得的接线证据

- 真实 CLI Watch：首次启动、cwd/argv、生成失败保旧、应用 build 失败保旧、修复换代、取消后 PID 退出。
- 真实 CLI Preview 仅构建：静态准入/交互拒绝、有效 overlay 资产复制、owned 资产拒绝、损坏/越界 Manifest 拒绝；用户目录快照不变且业务 init canary 未执行。
- 去掉 Watch 退出清理后原健康守卫失败；去掉 Preview owned 集合后原健康守卫失败。两条变异均可编译，恢复通过，未运行原生窗口。
- `internal/devx/process` 统一 Watch/Preview 构建与上下文测量的有界树执行，stdout/stderr 分离，保留退出码、取消与清理错误。

## 性能与发布阻断

菜单测量复用 scratch Ops，修复每项每帧新建 arena 的分配。
复用真实 Ops、50 帧预热后，组件 Layout 单独计时：菜单打开 7349ns/op、Modal 打开
873.6ns/op，均 0 B/op、0 allocs/op。输入 Router.Frame 在计时区外但每帧确实执行，
不能用这组数代替完整帧通过。

计入真实 input.Router.Frame 后：菜单打开 13279ns/op、272 B/op、6 allocs/op；Modal
打开 1111ns/op、48 B/op、2 allocs/op。无 Goxml 组件、仅一个可聚焦 Gio tag 的对照
为 532.4ns/op、48 B/op、2 allocs/op。分配 profile 指向 Gio 0.10.3 的焦点布局排序；
未改第三方依赖，**完整帧零分配门禁未通过**。这些是无 GPU、无窗口的微基准，
不是原生显示、冷启动、应用常驻内存或 `<5%` 整应用开销的证明。

补充真实输入与执行流回归后，组合覆盖并集按实际命中块逐包计算：CLI 85.27%、Preview
85.34%、Widgets 97.74%、Watch 81.41%、adapter 78.05%、process 71.30%。后三包
尚未达到 85%，不向上取整或改分母。并集来自 combined.cover、cli-extra.cover 与
process-direct.cover，同一源码块计一次；不是某一条单包命令的覆盖率。不用台账完整性 PASS 代替覆盖率或业务通过。

原生窗口、真实滚轮方向、DPI、IME 尚未执行；跨平台只有明确范围内的编译检查，
不外推 Linux/macOS 进程树运行能力。保留以上门槛，不关闭整张 DEVX/WIDGET 卡。
语言版本 1、缓存格式 8、生成输出修订 gen-4 均不变。
