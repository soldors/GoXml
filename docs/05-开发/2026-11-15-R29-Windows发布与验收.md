# R29 Windows/amd64 发布范围与验收

负责人于 2026-11-15 批准 Windows/amd64 源码发布。原生及组合受验提交为 `e7d0eaa6d6838e1ee5facc4832b2834566ce1892`，树为 `4195f82144c2eae252a8993afe0d7e0b7a62bf3d`。发布提交在该候选上补充正式文档。

## 发布合同

- **Hydration**。Windows/amd64 开发态可显式使用 `goxml watch --hydration` 与 `pkg/hydrationapp`。状态和端点发现按运行隔离，同项目并行 Watch 分别产出 `.goxml/run/<runID>/watch-bin-genN.exe`。共享生成事务通过 `.goxml/generate.lock` 在 Windows 上串行化，未启用 Hydration 的生成路径也使用该锁。回环 TCP 和显式 DTO 的开发态边界延续。CLI 联动端点默认满额拒绝（`reject`），可显式选 `evict`。直接构造的 Session 零值采用 `evict`。默认容量为 4096，旧记录仅供只读回退。
- **DataGrid**。`EnableHorizontalScroll` 与 `EnableMultiSelect` 默认关闭。应用可调用 `SortRows(less)` 进行显式稳定排序，选中项按 RowID 保留。多选模式下 Ctrl 切换单行，Shift 从锚点重新计算范围，普通点击收拢为单选。测试夹具的 P 键用于触发反序。
- **WindowHost**。`WindowHost` 与 `ProcessOptions.OnMainConflict` 随源码提供，维持候选等级。进程只认领一次 Gio Main。旧单窗进程入口遇到 Main 冲突时默认退出码为 1，显式选择 `MainConflictReturn` 时在通知 Observer 后返回。保留 `1e52179` 的宿主终态修复。
