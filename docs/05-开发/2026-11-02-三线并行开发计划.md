## 2. A线：跨包输出上下文

### 当前已核事实与待复现

当前 `resolveInput` 从源目录调用 `packageDirName`，`resolvedInput.pkgName` 注释也明确仍取源包；正式输出契约 §3.2/§4.1 要求可识别目标包。Codegen 的 `vmTypeExpr` 又把空 PkgDir 当作“与源 GXML 同包”，输出搬到另一包后不能继续把它当作与产物同包。这里是**源码确认的风险入口**，运行期缺陷须由首片真实 CLI 复现，不把静态阅读写成已复现。

### 两片开发

1. **目标包选择**：源目录和已初始化输出目录的 package 不同，静态页须落入真实目标包；多生产包、非法构建约束必须在写盘前拒绝。源目录继续用于同包 ViewModel 解析，不能把 SourceDir 简单换成 out-dir。保留既有新输出目录兼容路径；若既有测试与正式契约有真实冲突，单列，不删除或改绿断言。
2. **绑定与事件跨包**：原本与 GXML 同包的 VM 移出输出后，类型引用、import 别名和构造函数参数仍正确；已有显式跨包 VM、输出回到 VM 包时不得自导入；覆盖合法类型别名、包名不同于目录名、GOFLAGS 标签与缓存重复生成。

至少交一组真实 CLI→生成→`go build` 的正反对照：静态页、绑定/事件页、非法目标、多包失败保持旧文件/Manifest、同输入字节确定。用仓库已锁定依赖的 go.mod/go.sum 和 replace 构造独立模块，不联网补依赖。

### 写入所有权

允许 `internal/cli/{cache_wire.go,pipeline.go,新增outdir专用文件/测试}`、`internal/compiler/pipeline/pipeline.go` 的输出上下文接线、`internal/compiler/codegen/{codegen.go,新增输出上下文helper/测试}`。Codegen 继续只消费 VerifiedDoc 和显式内部 Options，不读盘/加载包，不改生成构造函数公开形态。Analyzer/Parser/Expander、事务实现 commit.go、缓存格式与生成 Source 头格式本轮不重定义。

## 3. B线：Def/Slot 实例隔离

现有 `cloneNode` 复制节点、部分切片，但 BindingVal.Segments、事件实参、For/If 中引用仍需按实际数据结构核实是否共享。深克隆注释不等于深克隆已证明；这不是确认缺陷清单，也不要求为交付凑出产品改动。

1. **先复现再修**：同一 Def 两次调用分别传静态值/绑定/默认值，嵌套 Def 与 Slot 中的树不能串用。通过修改一个展开实例的已有切片元素验证隔离，不用 append 容量偶然变化代替深拷贝证据。若发现别名共享，局部修复，不引入新的语法、事件转发或模板运行时。
2. **嵌套替换闭环**：外层/内层 Props 默认值、If 两分支及 Slot 调用方内容，展开后 Raw/Segments/Attrs/Events 应保持语义一致；有效输入经真实 Parser→Expander→Analyzer→Codegen→Go 构建，重复展开字节确定。已有合法条件/循环组合必须保持。

写入仅 `internal/compiler/expander/**` 和自己的日志；允许在该目录增加独立测试驱动/夹具调用公开 pipeline，不能去改 A 所有的生产 pipeline/codegen 文件。未复现缺陷时交有判别力的集成回归与结论，禁止无依据重构。

**保持冻结**：SCOPE-006 候选、Prop/Each 同名裁决、Def.Events 向子节点转发、行内 Input 不在本次批准范围。若宏隐藏状态控件暴露 Key/Input 边界问题，提供最小输入和既有码/阶段依据；需要新诊断或语义裁决的部分隔离为提案，不阻塞可独立接纳的克隆修复。
