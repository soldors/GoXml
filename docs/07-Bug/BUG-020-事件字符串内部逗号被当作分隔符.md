# BUG-020：事件字符串内部逗号被当作分隔符

- 级别：P2，合法既有字符串实参被错误拒绝。
- 状态：已复现、隔离修复及包回归通过，交叉审核/组合接纳见[本批记录](../06-测试/2026-10-31-并行开发验证记录.md)。

## 复现与根因

合法调用如`Click="Record('left,right')"`经Expander被直接按逗号Split，拆成两个不合法实参，出现EVENT-005。问题在事件词法切分，不是Analyzer允许任意表达式。

## 修复与证据

仅在单引号字符串之外切分，保留原有字面量数据与既有语义；空实参、未闭合字符串仍拒绝。修前rc1，修后Expander与实际生成代码/点击回归rc0；畸形输入由真实pipeline在Load/Generate之前拒绝，调用计数均0且旧文件不变。见[event_strings_test.go](../../internal/compiler/expander/event_strings_test.go)、[event_string_gate_test.go](../../internal/compiler/pipeline/event_string_gate_test.go)和[编译器日志](../05-开发/dev-log/2026-10-31-compiler.md)。

对应已审核修复已按范围接纳主仓：字体3357d8d、窗口d37cc00、编译器与CLI9e81534。组合源包、相关主仓回归及构建/静态检查通过；具体覆盖与未执行项见本批验证记录。
