## 现象

同一份文档里，零分配要求在三处的措辞**不一致**：

| 位置 | 原文 | 是否有限定 |
|---|---|---|
| §3.2（第 167 行） | 静态页面在稳定帧的 `allocs/op` 必须为 0 | ✅ 静态页面 |
| §6.1（第 284 行） | 静态页面稳定帧 `allocs/op == 0` | ✅ 静态页面 |
| **§4 预算表（第 254 行）** | `\| 稳定帧 `allocs/op` \| **0** \| INV-PERF-2 \|` | ❌ **无限定词** |

§4 是读者最先查阅的"预算一览表"。丢掉限定词后，读起来像是
**任意页面**（含 `<For>` 列表页、绑定页）都承诺了零分配。

## 根因

三处内容同源，但是**手工维护**：§3.2 收紧口径时没有同步派生出来的 §4 预算表。
这不是抄写错误，而是"派生表格没有机械校验"造成的漂移（与 `BUG-006` 同源）。

值得强调的是：这**不影响** `BUG-003` 的成立——那边的判断依据是 §3.2 与 §6.1 **两处一致**
的口径；但如果以后只引用 §4，就会得出相反结论。

## 修复

未修。已裁决的处理方式：**不在当次修正里顺手动主契约**，理由有二：

1. 本次任务是修正 For/If 两处契约的引用错误，范围不应扩大；
2. 修改 §4 需要先裁决"§4 的本意是否是静态页面"，这是所有者待定的口径决策。

建议时机：另开一个文档修正条目，补上「静态页面」限定词，并同时校验 §3.2 / §6.1 / §4 三处一致。
