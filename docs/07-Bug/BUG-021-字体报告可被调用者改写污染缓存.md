# BUG-021：字体报告可被调用者改写污染缓存

- 级别：P2，诊断所有权泄漏影响后续真实Lazy消费。
- 状态：修复及作者外审通过，组合验证见[本批记录](../06-测试/2026-10-31-并行开发验证记录.md)。

## 复现与根因

Provider热命中已返回报告副本，但冷ResolveWithReport和LastReport仍暴露`p.last`。调用者改写报告或其Candidates/嵌套诊断后，会污染其他调用者；真实Lazy虽可Ready，Probe却带上另一观察者写入的错误。

## 修复与证据

系统命中、嵌入兜底、完全失败及LastReport统一复用既有copyProbeReport。修前六入口/路径反例rc1，修后实际Provider→Lazy/Done消费与受控并发观察者rc0；theme包86.6%。见[provider_report_test.go](../../pkg/runtime/theme/provider_report_test.go)及[运行时日志](../05-开发/dev-log/2026-10-31-runtime.md)。沿用error对象原身份，不做通用反射深拷贝；Faces共享切片的既有契约不在本修复中改变。
