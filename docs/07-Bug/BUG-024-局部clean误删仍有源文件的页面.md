# BUG-024：局部clean误删仍有源文件的页面

- 级别：P1，增量生成时误删已有页面产物。
- 状态：真实CLI复现与修复回归通过，审核/组合接纳见[本批记录](../06-测试/2026-10-31-并行开发验证记录.md)。

## 复现与根因

先生成home和detail，再仅对home执行`--clean`。旧逻辑把“不在本次keepSources”当成“源已不存在”，删除仍有detail.gxml的detail_gen.go。用户常见的单文件或子目录生成不等于整个module的完整输入清单。

## 修复与证据

只有对应源文件实际不存在才可成为清理候选；其他Stat错误明确失败，保护头/Manifest双重所有权仍必须满足。真实中文空格临时module中修前rc1（观察到误删），修后rc0且detail文件字节保持，真正孤儿仍可清理。见[clean_safety_test.go](../../internal/cli/clean_safety_test.go)与[CLI日志](../05-开发/dev-log/2026-10-31-cli.md)。
