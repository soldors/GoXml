# BUG-019：行事件生成丢失循环作用域

- 级别：P1，合法页面生成成功后Go编译失败。
- 状态：已复现、隔离修复及包回归通过，交叉审核/组合接纳见[本批记录](../06-测试/2026-10-31-并行开发验证记录.md)。

## 复现与根因

For行内按钮处于Else或取反If时，顶部事件轮询仍引用渲染作用域的`item`；事件实参或Key使用Index时残留`i`或缺少range索引。原实现把已生成的表达式按字符串前缀/逗号再改写，无法保留取反、括号和索引的真实作用域。

## 修复与证据

从Analyzer的ResolvedPath/事件Mapping直接按目标作用域渲染Key、实参和守卫；轮询/清理显式生成所需索引，不动字符串字面量。`TestForRowScopeGeneratedCode`四场景修前均实际Go构建失败（rc1）；修后两次输出一致，实际生成代码编译及无窗口合成点击通过。回归在[for_scope_regression_test.go](../../internal/compiler/codegen/for_scope_regression_test.go)，作者记录在[编译器日志](../05-开发/dev-log/2026-10-31-compiler.md)。不扩展嵌套For或性能验收范围。
