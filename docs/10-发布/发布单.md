### 4.1 Linux 产物原生依赖清单（必须写入发布说明）

实测 `readelf -d` 的 `NEEDED` 列表：

```text
libEGL.so.1            libwayland-egl.so.1     libwayland-client.so.0
libwayland-cursor.so.0 libxkbcommon-x11.so.0   libxkbcommon.so.0
libX11-xcb.so.1        libX11.so.6             libXcursor.so.1
libXfixes.so.3
```

终端用户安装命令（Debian/Ubuntu）：

```bash
sudo apt-get install -y libegl1 libwayland-client0 libwayland-cursor0 \
  libwayland-egl1 libxkbcommon0 libxkbcommon-x11-0 \
  libx11-6 libx11-xcb1 libxcursor1 libxfixes3
```

**发布要求**：Linux 产物必须在发布说明中列出上述依赖；建议同时提供 `.deb`/`.rpm`/AppImage 封装，把依赖声明进包元数据。缺失依赖时用户会看到 `cannot open shared object file`，属可预期的降级说明范围，不是缺陷。

发布前必须保存产物、日志、测试报告和本发布单的同一提交快照。
