## 5. S1 冻结结果（2026-10-19）

契约与决策记录：

- [`状态更新契约.md`](../../03-架构/状态更新契约.md)——接口形态、通知职责、
  共享责任、nil 语义、兼容性影响与冲突检查；
- [`ADR-0010`](../../03-架构/adr/ADR-0010-统一View接口与ViewModel引用持有.md)——
  为什么统一接口、引用持有、整窗失效、暂不 AOT Diff。

### 冻结要点

| 决策项 | 结论 |
|---|---|
| View 接口 | **不变**：`Layout(gtx, th)` |
| ViewModel | 绑定 View **持有引用**（`NewXxxView(vm)`），调用方管理生命周期，不支持隐式替换 |
| 构造 API | 静态页面 `NewXxxView()` 不变；绑定页面 `NewXxxView(vm)`，nil 明确拒绝 |
| 失效机制 | Runtime 轻量封装 `w.Invalidate()`，只请求重布局不改状态 |
| 失效范围 | 第一版**整窗**、**单窗口**（现有 API 即单窗口，如实写明） |
| 多页面共享 | 按窗口绑定关系通知；不引入事件总线 |
| 并发 | Invalidate 并发安全 ≠ vm 并发安全；vm 同步归调用方（诚实条款） |
| AOT Diff | 仅 S5 评估项，本契约不引入 |

### 核查修正（与最初推荐的两点差异）

1. **构造签名变化已确认**：现有 `NewXxxView()` 无参，绑定页面改 `NewXxxView(vm)`
   是**必要的生成签名变化**（仅影响绑定页面，静态页面不变）。
2. **多窗口**：现有 Run/RunWith/RunWindow 均单窗口，契约直接写明第一版
   单窗口，不留订阅系统悬念。

### 决策与后续验证归属

构造失败形式已按 S2 定为返回 error，失效入口已实现为 `RunWindowWithInvalidator`，三参→两参迁移已完成；真实生成构造函数 nil 回归已在当前工作区通过，提交证据待归档。通知合并和标准生产入口覆盖归 S3；AOT Diff/细粒度失效归 S5 评估。
