# R10 测量边界与跨平台路径

- 命令拦截器本身有成本。go.bat→Python→Go每次启动的成本会随批处理一起减少，
  所以带拦截器墙钟不能当普通CLI净收益；次数与无插桩墙钟应分开记录。
- AllocsPerRun必须绑定相同边界。Layout-only两侧都是0；加Router.Frame出现2，
  不能归因于shaping或宣称局部缓存省掉2次分配。应以真实录制次数证明命中。
- 测试子进程PASS不代表最后断言到达。独有完成标记必须置于最后断言后，拒绝内部Skip、
  零测试、FAIL和缺标记；以可编译提前return证明守卫判别力。
- 不同操作系统的路径身份不能一律小写。Windows别名可折叠，Unix不同拼写须保留。
- Git Bash只转换命令参数，不转换go.mod内容；替换路径写D:/...并对空格加双引号。
