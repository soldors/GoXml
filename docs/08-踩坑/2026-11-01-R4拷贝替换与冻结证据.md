# 拷贝隔离要覆盖替换阶段，冻结证据要核对Git树

1. 深拷贝cloneNode不代表展开结果独立。单段Prop替换若直接返回同一BindingVal，Segments会再次共享。用已有元素原地赋值检查模板、两个兄弟与多个嵌套调用，不能用append是否扩容证明深拷贝。
2. clean声明、交付文件清单与Git提交树必须逐项核对。报告提到但未跟踪的build测试不属于冻结SHA；应保留原证据，在新审核提交补纳并实际运行。
3. 生成import声明时分配的别名必须和类型引用使用同一份映射；不能渲染时改为layout_2却仍在正文使用layout.VM。
4. 外部SetText的ChangeEvent计数不等于用户按键次数。处理器后lastApplied如何更新也必须读清，不能由单一底层机制推出反馈循环。
