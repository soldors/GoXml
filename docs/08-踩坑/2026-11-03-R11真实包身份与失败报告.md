# R11 真实包身份与失败报告

1. 候选编译检查不是只把go build挂在流程末尾：须检查提交前的最终候选，命中也不例外。
   用户overlay、有效GOFLAGS和相对路径cwd必须一致，不能用新overlay悄悄遮掉原配置。
2. 新包检查优先保留真实import路径。Go支持overlay虚拟目录，不需要把包搬到另一个shadow路径，
   后者会改变跨包import与internal可见性，或在错误分支留下模块内目录。
3. 失败报告本身也有文件所有权。拒绝输出目录不代表finally可覆盖别人的日志目录；
   已有报告和固定.tmp都须保护，自有更新检查文件身份，报告失败不能吞掉业务原始失败。
4. 测试名和计数不证明前提存在：“两文件构建”须实际Generate两个SourcePath；
   200次重录不证明Ops或内存无泄漏；打印VM值不证明生成显示更新。
5. PASS须配最后断言后的独有完成标记，生产验收计数放在测试副本；注入锚点缺失必须报错，不能静默跳过。
