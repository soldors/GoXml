# PIT-017：真实子进程环境必须贯穿验证

## 实际教训

在父进程环境下解析测试profile成功，不能证明真实执行时经launcher构造的最小环境同样可用。本轮CPU诊断exe成功，但随后的Go解析工具缺GOCACHE/LocalAppData失败，整批按规则停止。原始失败不是profile不可解析的充分证据。

## 防范

- 分别记录宿主、诊断exe、辅助Go工具的argv/env增删与实际runtime事实；不要把父进程环境填成子进程实测。
- 测试从最终入口穿过实际launcher和build_env，而不是绕过它直接运行解析函数。
- 明确辅助工具需要的缓存/临时目录定位，使用已安装工具，不为缺变量安装新组件；保持A/B诊断环境条件原样。
- 正常、变量缺失、错误目录、进程非零、输出部分写入、释放失败都应有明确结果；无效即停，不改历史valid。
- 合成测试和真实样本单列；修复后新实验用新身份/许可，旧批次保持失败证据。
