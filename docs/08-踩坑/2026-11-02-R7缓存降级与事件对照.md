# R7 缓存降级与事件对照

## 缓存不能建模，不等于业务不能执行

把缓存辅助函数移到生产入口前时，要重新区分错误用途。go.work使单模块依赖快照不完整，因此缓存保守miss；它不意味着Go上下文无法测量，也不意味着合法workspace不能生成。若直接把辅助error上抛，局部重构会造成原来成功的工程被拒。回归要覆盖“生成成功但缓存持续不命中”，不能只检查错误字符串。

GOENV持久化值也不能通过父进程os.Getenv推断。显式GOFLAGS=-mod=readonly会遮蔽GOENV中的-tags；测试必须先断言实际go env值。空GOFLAGS值则不遮蔽GOENV文件。对照环境只能放自有子进程/测试作用域，不能改用户GOENV或系统配置。

## 测试名称不能替代场景事实

“同帧Return”若没有同帧外部同步，不能证明同步与输入碰撞正确；“MaxLen追加”若处理器只原样回写，不能证明非幂等Append有界；空投影反例要实际包含Filter与外部写入。检查输入夹具和事件顺序，不凭PASS名称归因。

didSync是帧内局部量，不代表其门控只丢程序化echo。Editor.Update仍可把真正的用户编辑写入编辑器，再被continue丢掉通知，留下Editor/模型/Submit永久分裂。quiet帧计数不增长只是有界性证据，不是值一致性证据。

## 用mtime哨兵证明重写，给台账保留真实质量

同字节生成不一定经过写入。将自有临时产物mtime设为旧哨兵：缓存命中应保持哨兵与Manifest，--no-cache应离开哨兵且字节仍相同。这样不用sleep等待文件系统时钟，判据也不会只证明“内容相同”。

JSONL必须逐行解析。作者有28行不等于28条可消费记录；本轮C作者第23–28行6行非法JSON，B首败stdout被覆盖，均保留原样并注明缺口。独立复算和新组合检查另写真实argv/起止/raw，不回填作者未记录的时间，也不把重跑输出冒充首败日志。
