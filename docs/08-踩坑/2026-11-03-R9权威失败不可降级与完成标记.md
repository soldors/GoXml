# R9 踩坑记录

1. **拿到权威错误后不能换宿主答案。** go list判目标多包，MatchFile在宿主筛出一个包
   并不构成兼容回退。将错误消息子串当“未初始化”会把真实拒绝转成成功写盘。
   真正空目录用目录事实证明；文件选择由目标Go决定，其他错误显式失败。
2. **-e本身既不正确也不错误。** go list -e让错误变成结构化对象，消费Error/InvalidGoFiles/
   选中集及唯一性才有意义。只取Name或首行会掩盖错误，不用-e又凭stderr猜类别同样脆弱。
3. **SCEN不是DONE。** 中途打印观测值后return仍可能子测试PASS。每场景最后断言后
   发专用完成标记，并拒绝Skip/零测试/失败，整行匹配防id前缀误命中。
4. **重跑不靠删旧报告。** 入口拒绝覆盖是防线；测试为绕过它删除原文件，反而破坏首败。
   新调用分配独占目录，先前文件哈希保持不变，“本次新报告存在”不能靠读旧文件证明。
5. **脱敏须枚举所有公开出口。** 正常台账安全不代表锁busy早退也安全。私有恢复token
   与公开指纹分别保存；脱敏返回副本，不能损坏释放所用的真token。
6. **重跑通过不是根因证明。** 像素差1和后来通过说明可复现性/稳定性待查，不自动说明
   原因是光栅化，也不能用“不改这个文件”排除共享状态影响。保留首败、分开标事实与推断。
7. **状态条目不等于文件数。** 默认status可折叠未跟踪目录，63条与93文件可同时成立。
   更新保护必须展开、逐字快照；计数变化不直接等于用户内容丢失或改动。
