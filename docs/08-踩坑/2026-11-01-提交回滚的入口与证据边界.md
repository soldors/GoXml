# 提交回滚的入口与证据边界

1. **不要只检查当前失败对象。** 后序 Lstat/备份失败时，当前文件可能完全没动，前序文件却已被覆盖。回归应覆盖首项失败、后序失败、前序新建/覆盖混合以及恢复本身失败。
2. **断言真实备份路径。** 本实现的备份是 `staged.tmp + ".bak"`，检查 `target + ".bak"` 即使永远不存在也会绿。结合实际 staged 路径和目录残留枚举，才能证明清理。
3. **失败必须命中声称的阶段。** 目录目标可能先被 readOutput 拦下，不是提交期反例。用普通目标文件共享句柄和 stderr 操作信息，确认失败来自后序备份 rename。
4. **内容变化要有独立对照。** 只改 ViewModel 字面值可能不改变生成 Go；使用 GXML 结构变化，并验证成功对照的产物哈希确实不同。
5. **单文件替换不等于批次原子。** 逐项替换可在后续失败时恢复，但观察者可能看到中间状态；进程被强杀和断电也可能留下备份。不要把本批进程内恢复写成全场景原子保证。
6. **保护头不是完整所有权。** 用户可以保留或复制生成文件头；排除文件仍须满足相应 Manifest/Source 等所有权约束，不能仅凭标记就漏掉参与构建的用户源文件。
7. **保持测试注入局部。** 文件系统故障经按值 fileOps 注入，避免修改生产包级全局钩子。合法对照与判别红都应经过同一真实消费点。
