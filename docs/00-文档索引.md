## 架构红线

1. **Windows 侧 Zero-CGO**：Windows 构建必须 `CGO_ENABLED=0`，产物单文件。**Linux/macOS 允许 CGO**（Gio 后端依赖），新增系统依赖须登记到平台矩阵。见 [ADR-0007](03-架构/adr/ADR-0007-Zero-CGO降级为Windows侧约束.md)。
2. 严禁运行时解析 XML 或 CSS，所有转换必须在编译期（AOT）完成。
3. 严禁运行时反射脏检查，数据对比必须由编译器硬编码生成。
4. 原生文件弹窗等阻塞操作必须强制异步化，禁止阻塞 UI 渲染线程。
5. 严禁在帧热路径制造堆分配：静态子树必须宏固化，大列表必须虚拟化，禁止帧内拼接显示字符串。

> ⚠️ 原第 1 条「严禁引入 CGO，三端一键交叉编译」已于 2026-10-18 修订。真机实测确认 Gio 在 Linux 上穷举 5 种 build tag 组合均无法 `CGO_ENABLED=0` 构建，该要求物理不可实现。详见 [ADR-0007](03-架构/adr/ADR-0007-Zero-CGO降级为Windows侧约束.md)。
