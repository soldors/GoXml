## 三、沉淀到知识库的要点

### 3.1 契约驱动开发降低返工，但有个前提

**证据**：Analyzer 五步每步都先冻结契约再实现。其中三次在实现时发现契约问题：

| 阶段 | 发现 | 处理 |
|---|---|---|
| 第 4 步 | `EVENT-007`（方法有返回值）**从未分配码** | 新增码并同步目录 |
| 第 4 步 | `EventArg.Literal` 注释称「保留原文」，实际剥了引号 | 修 Expander |
| Codegen | 契约 §4.3 的 `Layout` 没有主题参数，但渲染必须有 | 新增 §4.3.1/§4.3.2 |

**判断**：契约先行确实让问题在写代码前暴露，但前提是「写契约时真的核对相邻契约」。
`Layout` 缺主题参数这个矛盾，是两份**已冻结**文档互相冲突——**冻结不等于一致**。

**改进**：冻结新契约时交叉检查它引用的其它契约，而不只看自身完整性。

### 3.2 手写门禁会「自证」，必须从源码推导

**证据**：`diagdoc` 的三态清单（`implementedCodes` / `frozenCodes`）是手写的。
Analyzer 的 11 个码全部实现并发射后，清单仍声称「未实现、不会发射」；
而旧测试**只校验两个手写清单互不重叠**，从不读代码——测试一直是绿的。

**改进**：新增 `emission_test.go`，用 `go/ast` 解析源码，验证每个 `Code*` 常量
都有调用点、都登记、登记的符号真实存在。并做反向验证（临时插入死常量，门禁确实失败）。

**结论**：**无法失败的校验不构成门禁。** 已写入质量门禁规范 §2.2.1。

### 3.3 状态漂移是系统性的，不是粗心

**证据**：四轮文档审计，每轮都发现「当前状态」类表述过期：

| 轮次 | 典型 |
|---|---|
| 第 1 轮 | 文档索引标「Q7 待确认」，而 Q7 早已冻结 |
| 第 2 轮 | `代码生成输出契约` 全文没提 `VerifiedDoc` |
| 第 3 轮 | 7 处仍写「编排层未验证」，而它已实现 |
| 第 4 轮 | `dev-log` 落后 3 个提交 |

最极端的案例：`dev-log` §7 写下「无窗口运行入口」，**十分钟后** `eb8a7b2` 就把它推翻了。

**根因**：同一个「当前状态」被复制到多处，每次推进都要同步 N 份，必然滞后。

**改进**（已在执行）：

- 状态只由 WBS / 任务卡维护
- ADR / 规范 / 契约只描述设计，不写「已实现 / 覆盖率」
- 验收报告的未验证项必须带**基准提交**；状态变化时更新当前结论并保留原基准

### 3.4 并发写入是真实存在的风险

**证据**：提交 `eb8a7b2` 混入 4 份并非本会话创建的交接包（时间戳 01:19–01:20）；
`ebab6b5` 中另有 3 个文件由并发会话修改。

**判断**：`AGENT.md` 写着「多 AI 协同」，在 01:19 真实发生了。这不是异常，是常态。

**改进**：

- 提交前用 `git diff --cached` 逐文件核对；发现非本方改动时**停下确认**，不自行处置
- 提交信息中分开注明两类来源，不把并发产出记为自己的
- 交接包规则从「每次必写」改为「按需写」，减少无意义冲突面

### 3.5 安全审查发现了真实缺陷

**证据**：`Commit` 用 `filepath.Join(dir, a.OutputName)` 且不校验 `OutputName`，
`../` 可把文件写到目标目录之外。探针直接复现（见 `BUG-001`）。

**判断**：根因不是「少写一个校验」，而是**信任模型缺失**——`Artifact` 字段全部导出，
任何调用方都能构造，`Commit` 却假设它来自 Codegen。

**改进**：安全审查报告新增「信任边界」表，把 `Artifact` 标为**半可信**；
`Commit` 自行防守而非依赖上游。

## 五、下次要改的流程

1. **冻结契约时做交叉检查**：不只看自身完整性，还要核对它引用的其它契约
   （`Layout` 缺主题参数的教训）。
2. **新增门禁必须做反向验证**：临时注入一个应被拦住的输入，确认门禁真的失败。
3. **状态描述单一来源**：新写任何文档时，不复制「当前状态」，只放指针。
4. **提交前逐文件核对暂存区**：并发环境下这是必要动作，不是谨慎过度。
5. **安全审查提前**：`TASK-SEC-001` 的前置条件曾被绕过（Codegen 先落地、审查后补）。
   实际顺序反了——这次后果可控，但那是运气。
