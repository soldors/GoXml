# R12 缓存升级与检查失败验收

## 组合门禁

- 用 R11 CLI 生成并预热旧 v7 缓存。项目中的目录名为 model，ViewModel 类型声明包为 vmodel，视图包为 edit。
- 用 R12 CLI 在同一工程执行 `generate --check`。旧键因生成器身份变化未命中，输出改为引用 vmodel；保护头 GXML 版本保持 1。
- 同修订再次执行，缓存命中仍做提交前检查。核对产物、Manifest 和缓存的 SHA-256 及 mtime 不变。
- 引入目标包 Go 类型错误。检查失败后仍保留产物、Manifest 和缓存的字节及 mtime；移除错误后再次命中并能构建工程。
- 工程入口分别测试原生提交前检查失败和后续入口构建失败。仅运行离屏用例，窗口入口只构建。

原始命令与双通道日志保存在本轮交付的 `product-r12/coordinator/`。旧二进制来自 R12-A 的基线复现，组合二进制由本轮隔离树构建。
