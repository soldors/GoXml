# R14 提交前编译与维护验收

- 用 R13 CLI 为含导入名冲突的双视图预热旧缓存。R14 CLI 在同一工程自动失效旧记录、生成消歧后的 Go 代码并通过检查，再次运行保持真命中。
- 移除一个页面源，在存活目标注入 Go 类型错误。即使设置 GOFLAGS=-n，检查仍编译并拒绝提交，两个旧生成物、Manifest 和缓存的字节及 mtime 保持一致，清理未开始。
- 修好后仅清理有归属证明的孤儿，恢复页面后可重新生成并构建入口。工程脚本同时验证用户接管、归属歧义、范围外存活源及人工构造争议。
- 真实窗口入口只构建。通过离屏事件验收覆盖双视图交互，证据保存在本轮交付目录 `product-r14/coordinator/`。
