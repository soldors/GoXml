# 测试计划

完整测试和质量门禁以 `docs/06-测试/测试与质量门禁规范.md` 为准。

- 契约测试：`contracts/` 必须 100% 通过。
- 编译器核心：Parser/Analyzer/Codegen 行覆盖率 >= 85%，核心解析路径 >= 90%。
- Golden 测试：验证生成代码确定性、格式、包名、import 和无反射约束。
- 端到端测试：Parser -> Analyzer -> Codegen -> gofmt -> go build 全链路通过。
- 竞态测试：Runtime、Lifecycle、Hydration、Watch 和平台回调执行 `go test -race`。
- 跨平台网关：完整生成应用在 Windows/Linux/macOS 下 `CGO_ENABLED=0` 交叉编译通过。
- 平台 smoke test：在宿主机验证剪贴板、文件弹窗、托盘和菜单的成功、取消、权限和不可用分支。
- 性能压测：生成版对比手写 Gio，固定环境下单帧 CPU 损耗目标 <= 5%，并**同时报告绝对 ns/op 与 allocs/op**；稳定帧 `allocs/op` 必须为 0。完整不变量与阈值见 `docs/03-架构/性能预算与优化策略.md`。
- 性能断言：`make bench-assert` 校验静态子树宏固化、零分配与万行虚拟列表单帧预算。
- 字体与文本：CJK 渲染、系统字体缺失兜底、中文 IME 输入与候选框定位见 `docs/03-架构/字体与文本渲染策略.md`。
- 生成代码不以行覆盖率作为主要指标，以编译、Golden、AST 和运行时 E2E 作为证据。
