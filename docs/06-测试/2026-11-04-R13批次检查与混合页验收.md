# R13 批次检查与混合页验收

- 以真实 CLI 与转发器统计 30 个目标包的 `go build` 启动次数。常规模式每组最多 12 个目标，比较 R12 的逐包检查与 R13 的有界分组。
- 同名 main、含空格的相对 modfile、用户 GOFLAGS 输出路径、非默认构建模式和链接失败分别有回归。检查失败发生在产物、Manifest、缓存提交以及清理之前。
- 双视图工程对照批次和逐页的生成结果。全命中仍执行检查；坏页整批拒绝、保留两页旧产物；修复后恢复命中并构建。原生工程命令只启动一次 generate，窗口入口只构建。
- 混合页矩阵通过离屏 Router 验证约束、动态文本、If、稳定 Key 行事件、主题与 DPI，以及双实例隔离。

覆盖范围为受影响包、工程脚本、文档门禁与离屏行为。命令和原始日志见本轮交付目录 `product-r13/coordinator/`。
