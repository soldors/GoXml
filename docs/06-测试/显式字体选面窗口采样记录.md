# 显式字体选面：固定快照真实窗口采样记录

本记录登记显式 opt-in 实现的本机运行证据，不是 FONT 正式验收，也不修改既有预算或 WBS。默认 `NewLazy`/Provider 探测和回退策略保持原行为；显式入口为 `theme.LoadSelectedFaces` 与 `theme.NewLazyWithSelection`。

## 固定对象与方法

- 生产实现提交：`97c0f7b645f1b2bb596df8382fd4693cc09e8d11`；探针快照：`2ed565c8b277e54b75b061f3cb283f9a83bccda2`。之后本次文档提交没有修改 Go 源码。
- Windows/amd64，Go 1.26.1，CGO_ENABLED=0，字体 msyh.ttc（19,704,352 B、两面），协议 `face-selection-window-v1`。
- 两层分别为 child 实测 GOMAXPROCS=2 与删除该环境变量后 runtime=20；四 case 为 default-lazy、selected0-lazy、selected1-lazy、selected-all-lazy。
- 先8次 smoke，再按预登记随机顺序执行30 blocks×8=240个独立进程，每格n=30，无失败、替补或重试。两批不混用，环境层不合池。新进程不代表操作系统/文件缓存冷启动。
- median 为排序中间两项均值；p95 为 nearest-rank 第29项。配对差先在同block计算 selected−default，再取中位数，不等同两个中位数之差。
- 协调者直接从240份raw字节独立核验与复算；ZCode另用自有解析器/统计实现复核，逐格一致。PID有复用，但240个PID+创建FILETIME组合唯一；monotonic区间无重叠。

单面选择的 Ready 中位数下降32.85%–35.24%，同block配对中位差为−57.01至−59.35ms；四组中分别30/30、30/30、29/30、30/30为负。selected-all 的 Ready 配对中位差为+2.20/+3.68ms，未出现单面收益。选择路径有意减少返回面数，不意味着整个TTC语义不变；`NewLoaders`仍枚举全部面头部，不能把收益全部归因于某个内部函数。

## 计时与结论边界

M1是App内部CreatedAt至首帧处理开始；FontInit→Ready是字体初始化入口至最终主题LoadedAt；Request→Loaded是后台请求至完成。它们互不替代。239/240条首帧早于最终字体完成、首Layout使用临时主题；seq217合法地先加载完成，首Layout已用最终Shaper，changes=0，M1=186.0084ms，保留在统计中。15条CreatedAt与InitAt不同，未混用起点。

最终Layout与FrameSubmitted仅为代理，不代表实际呈现。未做RSS/Heap预算、race、跨平台运行、跨机器、OS缓存冷启动或M1根因profiling；不把headless约50%解析收益换算成M1收益，也不以本批比较历史快照的快慢。

全仓测试/覆盖率、vet、Windows amd64/arm64 build由生产集成轮执行；探针专项28顶层/71子测试、vet/build由协议收口轮执行。之后生产及探针源哈希未变，文档收口仅运行文档门禁和diff检查，不重复全仓或重新生成性能样本。
