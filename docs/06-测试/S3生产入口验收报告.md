## 2. 验收范围

本报告验证生产形态的持久句柄 API：

```text
NewApp(view, theme, config) -> *App
后台 goroutine 修改已同步的 ViewModel -> App.Invalidate()
App.Run() -> Gio 主循环 -> 后续 FrameEvent -> Layout 读取新值
```

同时验证 Run 前调用 `Invalidate` 的安全语义和并发失效入口。S3 不覆盖 Linux/macOS
真实窗口、发布级性能、Generate CLI、AOT Diff 实现或多窗口订阅。

## 3. 命令与结果

| 命令 | 退出码 | 结果 |
|---|---:|---|
| `go test -count=1 -run '^TestApp' -v ./pkg/runtime/app` | 0 | 3 项通过 |

通过用例：

- `TestAppInvalidateBeforeRunIsSafe`：Run 前连续调用两次 `Invalidate` 安全返回；
- `TestAppRunDrivesAndInvalidateRefreshes`：真实窗口观察 `AAAA -> WWWWWWWW`；
- `TestAppConcurrentInvalidate`：8 个 goroutine 各调用 100 次，无 panic。

## 4. 边界与限制

- ViewModel 字段同步仍由调用方负责；`Invalidate` 并发安全不等于字段读写并发安全。
- `RunWindowWithInvalidator` 的 S2 受测证据仍见 [`S2状态通知验收报告.md`](S2状态通知验收报告.md)；
  本报告验证的是生产 `NewApp`/`Run`/`Invalidate` 句柄形态。
- 当前工作区的动态 demo 冒烟属于补充证据，不替代正式窗口验收。

## 5. 结论

S3 生产入口在 Windows/amd64 当前提交上通过本报告范围内的三项测试。
这不代表跨平台窗口行为、发布验收或完整产品链路已经通过。
