# 2026-10-31 稳态帧测量与判定记录（首帧之后）

> 状态：开发/测试记录；**非**性能验收、非窗口执行许可。基线：集成树 HEAD `c1da35e`，主仓库 `a2dcff9`；gioui.org v0.10.3、Go 1.26.1。
> 执行者：DeepSeek（独立方向 A 开发）。真实 GUI 窗口：测量用 2 个（probe 5 帧 + 测量 1 次），均自终止、0 残留；**未改生产源码、未 Git 写**。

## 目的

M1（首帧止点）已单独测量并有结论；本记录补足**首帧之后（post-M1）稳态帧**的成本与空闲行为观测，判断是否存在值得做的优化点。**不涉及**诊断宿主/执行/复审线。

## 方法（全部可复现，见 `handover/MEASUREMENT-MANUAL.md`）

1. **契约核查（R-S1）**：gioui `app.NewContext` 在 `app/app.go:100-102` 每帧调用 `ops.Reset()`；`pkg/runtime/app/app.go:374,464` 跨帧复用 `var ops op.Ops` 为正确做法。实测 NewContext **10 ns/0 alloc**。
2. **无窗口微基准（R-S0）**：`app.NewContext(&ops, FrameEvent{…}) + widget.Label.Layout` 在进程内复现 `frame()` 路径（`bench/`，独立 module，离线）。
3. **分配归因**：`go test -cpuprofile/-memprofile` + `go tool pprof -top`（`logs/`）。
4. **真实窗口对照**：最小自终止程序（`realwindow/`）测 static vs churn 每帧耗时与空闲产帧。

## 关键数据

| 观测 | 结果 |
|---|---|
| headless Frame20Labels（静态） | ≈24–30 µs/帧，0–4 allocs |
| headless Frame20Varied（每帧换文本） | ≈0.73–1.0 ms/帧，≈2.6–2.9k allocs，≈1.2 MB/帧 |
| 分配热点（alloc_space top） | `go-text opentype`（`ParseGlyf/parsePoints/findTableBuffer`）+ `internal/ops.WriteMulti` |
| 真实窗口 static | ≈8.28 ms/帧 |
| 真实窗口 churn | ≈8.33 ms/帧（Δ≈0.05 ms） |
| 空闲 800 ms 到达帧数 | **0** |

## 判定（可证伪）

- 静态文本（真实 UI 常态）每帧成本 ≈ 16.7 ms 预算的 **0.15%**、近 0 分配 → **"整形/布局复用"收益趋零**。
- 真实窗口 static≈churn≈8.3 ms（呈现/vsync ≈120Hz 主导）→ churn 的 glyf 解析/op 分配**未抬升真实帧时**。
- 空闲 **0 帧** → **无空转重绘**。
- **决定：不为稳态文本出优化候选（NO_CANDIDATE_WITH_EVIDENCE）**；保留 `bench/`+`realwindow/` 作回归护栏与未来（无 vsync/高刷/更长 churn）条件性复测。

## 边界与未做

- 单机 n=1、无 p95/分布；headless 不含 GPU 绘制/呈现/vsync；churn 为对抗性 20 标签/帧。
- 未测真实页面分布；未做无 vsync 设备；不称"提升 X%"，不作性能验收。
- 已知缺口：真实窗口下若关闭 vsync/更高刷，计算占比可能上升——需该硬件条件重测。

## 更正（CPU 时间补测，2026-10-31 追加）

初版仅测**墙钟帧间隔**（static≈churn≈8.3ms），据此称“churn 用户/计算成本被 vsync 吸收、不可见”——**过强**。补测进程 CPU 时间后：**churn 每帧 CPU 1.30→3.56 ms（+174%）**，墙钟仍 8.18→8.47ms（vsync 掩盖）。
- 更正口径：**帧率/延迟不受影响；CPU/能耗真实上升**。
- 对候选：60fps/120Hz 预算下无掉帧，故仍 NO_CANDIDATE；但“高 churn 文本降 CPU（glyf 解析/op 写）”登记为量化假设 H2，需低帧预算设备证据再定。
- 证据：deepseek/steady-state-r1/cpu-addendum.md、logs/realwindow-v2.stdout.bin。
