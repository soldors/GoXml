# 验收用例

- 适用版本：GXML v1、Goxml v0.1.0-alpha
- 依据文档：`docs/02-需求/需求清单.md`、`docs/03-架构/`、`docs/06-测试/测试与质量门禁规范.md`
- 当前基线：设计已冻结，实现和运行验证尚未完成

## 状态约定

| 状态 | 含义 |
|---|---|
| 未执行 | 尚未运行验证命令 |
| 通过 | 命令成功且证据满足期望结果 |
| 失败 | 实际结果不满足期望结果 |
| 阻塞 | 因环境、依赖或未完成实现无法执行 |
| 不适用 | 经评审确认不属于当前发布范围，并记录原因 |

验收不能只填写状态。每条用例完成后必须记录命令、提交版本、运行环境和证据位置；失败或阻塞必须关联 Bug 或风险项。

## 验收记录要求

每次发布候选版本都必须将本表复制或引用到 `docs/06-测试/` 下对应里程碑的验收报告，并补齐：

- 执行日期、提交 SHA、Go/Gio 版本和操作系统；
- 实际命令及退出码；
- Golden、日志、构建产物或截图的路径；
- 失败项、阻塞项、风险接受人和后续任务。
