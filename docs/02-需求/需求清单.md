# 需求清单

## REQ-001 GXML 语法解析与强类型属性转换
- 优先级：P0
- 规范依据：docs/03-架构/GXML语言规范.md（GXML v1，已冻结）
- 功能：解析标签、控制流（<If>/<Then>/<Else>/<For>）、属性（EdgeInsets/Color/Binding/Event），并在出错时返回 file:line:col: code: message。

## REQ-002 Gio 代码生成与组件宏内联展开
- 优先级：P0
- 规范依据：docs/03-架构/代码生成输出契约.md（v1，已冻结）
- 功能：将 NodeIR 转换为确定性的纯 Go 代码，处理 <Def>/<Slot> 宏替换、组件静态注册、生成文件保护、失败回滚、Manifest 清理、增量缓存与 //go:embed 静态资源注入。

## REQ-003 编译期 AOT 零反射浅对比状态管理
- 优先级：P0
- 规范依据：docs/03-架构/AOT状态Diff语义.md（v1，已冻结）
- 功能：生成 ShadowState、节点级 Dirty Mask 和硬编码字段对比函数；状态未改变时复用绘制 Macro，交互控件仍需执行输入处理。

## REQ-004 单窗口路由与 MacroOp 转场动画
- 优先级：P1
- 功能：基于 switch 的虚拟路由，动画期录制旧页面宏快照，避免双倍业务计算。

## REQ-005 Live Reload 与静态预览器
- 优先级：P1
- 功能：fsnotify 监听、进程树级清理与重启、ViewModel 状态 JSON 序列化暂存恢复。

## REQ-006 Zero-CGO 原生系统交互
- 优先级：P1
- 功能：提供纯 Go 剪贴板、异步原生文件弹窗、系统托盘与系统级菜单栏。
