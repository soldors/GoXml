# 字体正式验收执行方案（FONT-001-D 正式验收 / R23-R1-B B3）

> **2026-11-06 工具状态**：随仓 runner 与集中返修已经发布，入口为 [字体工具 README](../../scripts/font/README.md)。执行方案不是采样授权；准备态 rc=2，不产样本，不把 summary 可用当阈值达标。旧历史样本与当前方案不混算，整体正式字体验收仍未完成。

> 本文件是**执行方案**，不是执行结果，也不改通用总览/WBS/README，不设阈值、不新增 family、不开窗口。
> 复用既有 `scripts/font/*`（`font-init-v1` 口径）与 `pkg/runtime/app/testdata/m1nightprobe`（`comparison.go`）。
> 既有事实（协调者复核已确认）：**同步/异步同源比较机制已存在**（`font-init-v1`），**真实 App+M1 探针已存在**（`m1nightprobe` 用 `NewApp/NewLazyApp/FirstFrame`）；本方案不声称二者不存在。原 `font_lazy_strict_test.go` 不解冻。

## 1. 被验对象与身份（可复现锚点）

| 项 | 要求 |
|---|---|
| 被验源码 SHA | 完整 40 位提交 SHA（被验快照 HEAD），`git rev-parse HEAD` 记录到证据；不得用短 SHA 或分支名替代 |
| 二进制身份 | 每次采集用被验 SHA 重新 `go build`；记录构建产物路径 + 二进制 SHA-256；同一比较内 sync/lazy 必须**同一二进制** |
| Go/工具链 | `go version`、`GOOS/GOARCH`、`CGO_ENABLED=0`、`GOMAXPROCS`（采集器构建固定 2，运行时按 `-RuntimeProcs` 记录） |
| 机器/图形会话 | 机器标识、会话标识、Windows 版本、时钟分辨率实测（`time.Now` 步长探针结果） |
| 采集器版本 | `scripts/font` 与 `m1nightprobe` 的源码 SHA-256 一并登记 |

## 2. 三种模式（复用 `font-init-v1`）

| 模式 | 入口 | 用途 |
|---|---|---|
| **none** | 不启用字体比较（默认 M1 采样） | 基线：无字体加载的 M1，仅作参照，**不用于**关闭 D-ACCEPT-02 |
| **sync** | `collect-m1.ps1 -CompareFonts -Load sync` | 同步冷字体路径总耗时 |
| **lazy** | `collect-m1.ps1 -CompareFonts -Load lazy` | 异步懒加载最终主题就绪耗时 |

模式只接受 sync/lazy（none 为参照）。**sync 与 lazy 分组统计，严禁混成一个分布**。

## 3. 同源起止点（`font-init-v1` 已定义，直接复用）

| 字段 | sync | lazy |
|---|---|---|
| `fontInitAtNs` | 调 `theme.NewThemeWithReport()` 前 | 调 `theme.NewLazy()` 前，随后同一 Lazy `NewLazyApp` |
| `fontReadyAtNs` | 调用成功返回后立即取时 | `Lazy.Report().LoadedAt`（后台最终主题完成时刻） |
| `fontReadyElapsedNs` | ready−init | 同左（含临时主题+Request 同步部分+后台加载+调度等待） |
| `fontToFirstFrameElapsedNs` | `App.FirstFrame().FirstFrameAt − fontInitAtNs` | 同左 |
| 原 `m1ElapsedNs` | 构造入口→首帧处理开始 | 同左 |

- 所有时间来自本进程 `time.Now()`，**不注入虚拟时钟**。
- 异步 Ready 与首帧**无预设先后**；禁止把两区间相减称为"净收益"。
- 零耗时可能因粒度出现，带 `Measured=true` 保留，**不得据此宣称零成本**。

## 4. Ready 与 FirstFrame 分别判定

- **Ready**：lazy 必须到 `LoadReady`、`Err==nil`、`LoadedAt` 非零；首帧已到但仍 `Loading` → **不算**完成时间样本成功。
- **FirstFrame**：`App.FirstFrame().Measured()==true` 且 `FirstFrameAt` 非零；与 Ready 独立记录，不互相替代。

## 5. 独立进程与 Provider 缓存条件

- 每样本**独立 OS 进程**；进程内默认 Provider 未解析（Diagnostics nil），最终报告须 `ProbeRan=true`（进程内 Provider 冷缓存）。
- **不宣称**磁盘/OS 字体缓存冷。
- 同一可执行文件、Git 快照、源码哈希、机器、图形会话下按**预登记交替顺序**执行 sync/lazy：如 `S,L,S,L,…`（先验登记该序列，逐样本按序跑，不得先跑完全部 sync 再跑全部 lazy 冒充"交替"）。
- 每样本为**独立进程单次运行**（`-Runs 1`）；交替由外层循环按预登记序列对每个样本调用一次采集器实现，而非两整批 `-Runs N`。
- 新批次与历史 `7f6621c` 的 90 样本**不得混用一个分布**；并行度策略不同的记录分组。

## 6. 窗口启动与关闭 / 人工观察项（正式执行时才开，本方案不开）

- 真实 App M1/比较探针会启动真实窗口：执行时须在**交互桌面会话**运行，`m1nightprobe` 以显式退出码（0/1/3）收口；超时/被杀/非零退出 = 无效样本，保留原始。
- **人工观察项**（须人工记录，单测不可替代）：窗口正常出现并渲染、首屏有 CJK 字形、无花屏/空字、标题栏可关闭、退出码 0。视觉判定单独登记，不与耗时样本混为一谈。
- 采集结束务必确认窗口关闭、进程退出、公共锁释放。

## 7. 无效/失败样本保留（不得剔除后宣称通过）

- 超时、失败、退出码未知/非零、被收集器终止、字段缺失、区间为负、`ProbeRan=false`、Ready 未到 → **不计入有效统计**，但原始输出与失败记录**全部保留**；不能用 sleep/删断言/重跑替换异常样本。

## 8. 采集与汇总命令（模板，执行时替换 SHA/路径；**真实公共锁**）

> **随仓入口（R24-A）**：本模板已固化为 `scripts/font/run-font-acceptance.ps1`（编排，不内建第二套收集器，
> 复用 `collect-m1.ps1`/`summarize-m1.ps1`）。它实现预登记交替序列、每样本独立 `-Runs 1`、原件不改、
> 派生唯一 ID 附原路径/ID/SHA、显式 `-AllowMixed` 分组，并对已存在目录/身份/缺行/重复ID/故障码 fail-closed。
> 准备态（不带 `-Execute`）只冻结序列并校验、**退出码 2（非通过）**、不调用采集器、不产生样本。
> 真实采样需 `-Execute` 且另有授权。合成回归：`scripts/font/test-font-acceptance-plan.ps1`（仅临时 mock，不采样）。
> 下列手工模板保留作执行语义参考；等价于入口脚本内部行为。
>
> **R24-A repair-r1 增补（F-A1~A4）**：入口在派生汇总后**读取真实 `summary/summary.json`** 并 fail-closed——
> `rejected==0`、`accepted==derived`（`summarize-m1.ps1` 语义：`accepted=valid+invalid`，invalid 是已标记子集、非拒收）、
> `invalid==本轮 rc=5 合法无效数`、`valid==derived-invalid`；汇总器进程 rc0 **不等于**业务通过。
> 预登记序列须**偶数、sync/lazy 数量相等且严格逐项交替**（奇数/不平衡/相邻重复一律拒绝）。
> `ExpectedHead` 须为完整 40 位十六进制 SHA（非仅长度）；每条记录 `load` 与 `baseSHA` 须与预登记模式及
> `ExpectedHead` 一致，不符在汇总前拒绝并停止调度、原件保留。准备态只校验 argv/序列/SHA 格式/目录唯一，
> **不**声称来源或汇总有效；执行态才绑定来源并核 `summary.json`。合成回归改用**真实 summarizer** + 真实结构记录。

锁：所有采集共用**同一把公共 Go 重负载锁** `D:/Codes/Goxml-night-reports/2026-10-27/heavy.lock`（`-LockFile` 指向它，不得用 `<evidence>/heavy.lock` 私有锁——私有锁无法序列化与其它公共采样/Go 任务的并发）。

**预登记交替顺序**（示例 N=6，登记序列 `S,L,S,L,S,L`；实际 N 由负责人定，序列先落盘再执行）：

```powershell
$lock = 'D:/Codes/Goxml-night-reports/2026-10-27/heavy.lock'
$tree = '<audit-tree>'; $sha = '<full-sha>'; $ev = '<evidence>'
$order = @('sync','lazy','sync','lazy','sync','lazy') # 示例，执行前冻结实际序列
if (Test-Path -LiteralPath $ev) { throw '证据目录已存在，拒绝覆盖' }
$null = New-Item -ItemType Directory -Path $ev
$order | ConvertTo-Json | Set-Content -LiteralPath (Join-Path $ev 'order.json') -Encoding UTF8
$derivedLines = New-Object 'System.Collections.Generic.List[string]'
$manifest = New-Object 'System.Collections.Generic.List[object]'
for ($i=0; $i -lt $order.Count; $i++) {
  $mode = $order[$i]
  $caseName = 'sample-{0:D2}-{1}' -f $i,$mode
  $out = Join-Path $ev $caseName
  & ./scripts/font/collect-m1.ps1 -RepoDir $tree -ExpectedHead $sha -OutDir $out `
      -Load $mode -CompareFonts -Runs 1 -Strict -LockFile $lock
  $rc = $LASTEXITCODE
  @{ index=$i; mode=$mode; exitCode=$rc } | ConvertTo-Json |
      Set-Content -LiteralPath (Join-Path $ev ($caseName+'-exit.json')) -Encoding UTF8
  # 5=样本已记录但Strict判无效，可以保留后继续；其余非零可能是锁/身份/证据/进程收口故障。
  if ($rc -notin @(0,5)) { throw "采集器故障 rc=$rc；停止后续调度，保留全部已录证据" }
  $source = Join-Path $out 'samples.jsonl'
  $rows = @(Get-Content -LiteralPath $source -Encoding UTF8 | Where-Object { $_.Trim() })
  if ($rows.Count -ne 1) { throw 'Runs=1必须对应一条原始记录，拒绝缺失或额外行' }
  $record = $rows[0] | ConvertFrom-Json
  $originalId = [string]$record.id
  if ([string]::IsNullOrWhiteSpace($originalId)) { throw '原记录缺少id' }
  $sourceHash = (Get-FileHash -LiteralPath $source -Algorithm SHA256).Hash.ToLowerInvariant()
  $record | Add-Member -NotePropertyName aggregationSource -NotePropertyValue @{
      path=$source; sha256=$sourceHash; originalId=$originalId
  }
  # 每次Runs=1的原id均可能是0001，只在新派生副本中加运行目录命名空间，原件不变。
  $record.id = $caseName+'/'+$originalId
  $derivedLines.Add(($record | ConvertTo-Json -Depth 20 -Compress))
  $manifest.Add(@{ derivedId=$record.id; path=$source; sha256=$sourceHash; originalId=$originalId })
}
$derived = Join-Path $ev 'derived'
$null = New-Item -ItemType Directory -Path $derived
[System.IO.File]::WriteAllLines((Join-Path $derived 'samples.jsonl'), $derivedLines.ToArray(),
    (New-Object System.Text.UTF8Encoding($false)))
$manifest | ConvertTo-Json -Depth 10 |
    Set-Content -LiteralPath (Join-Path $derived 'manifest.json') -Encoding UTF8
# 汇总器不递归搜集各sample目录；必须显式输入新派生samples.jsonl，并分组输出sync/lazy。
& ./scripts/font/summarize-m1.ps1 -InputDir $derived -OutDir (Join-Path $ev 'summary') -AllowMixed
if ($LASTEXITCODE -ne 0) { throw '派生汇总被拒绝；不将其写成采样通过' }
```

- 每样本**独占输出目录**（`sample-NN-mode`），ID 唯一；**失败样本保留原始 stdout/stderr 与退出码，不复跑替换**。
- `-Runs 1` 每次，交替由外层循环按预登记序列驱动；**不得**两个整批 `-Runs N` 后声称交替。
- `collect-m1` 的单次原始 ID 可能重复为 `0001`；上例只在新派生副本加命名空间，并附原路径/原ID/SHA，原始记录与时间/有效性不改。不能直接拼接重复ID或对父目录调用不递归的汇总器。
- `-AllowMixed` 只按来源分别统计，不混算 sync/lazy；无效记录仍保留。未完成的采样批次和未运行项目分别登记，不补齐虚构样本。
- 本模板的聚合/汇总路径以合成 fixture 核对，不是本轮新开窗口或新性能样本；真实执行仍需单独授权。
