# ADR-0002：采用 Vue 绑定与 Svelte 控制流混合的 GXML 语法规范
- 状态：已接受，v1 语义已冻结
- 冻结日期：2026-10-18
- 规范正文：docs/03-架构/GXML语言规范.md
- 核心决策：属性采用完整绑定 `{Path}` 与事件绑定（初版用 `@Event`，因 `@` 非合法 XML 名称已改为无前缀事件名，见 §5.1），控制流采用 `<If>/<Then>/<Else>/<For>` 标签，组件采用编译期 `<Def>/<Slot>` 宏展开，禁止复杂内联表达式。
- v1 边界：不支持运行时 XML/CSS 解析、任意 Go 表达式、隐式双向绑定、动态组件和命名插槽。
