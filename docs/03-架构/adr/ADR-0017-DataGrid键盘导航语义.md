# ADR-0017：DataGrid 键盘导航语义

- 状态：**已批准基础语义，发布验收未完成**
- 日期：2026-11-10
- 范围：`pkg/widgets.DataGrid` 的显式 opt-in 键盘单选与纵向导航
- 组合基线：`474dfb2a047ab19bc56a6093b13c32f7a0bbd204`
- 实现证据：R28-B `7e69a367a51cb40dbe5aef4e11931e7696c908d6`

## 决策

DataGrid 可以通过方法式 API 显式开启键盘导航；默认保持关闭。批准范围为只读、单选、纵向导航：`Up`、`Down`、`Home`、`End`、`PageUp`、`PageDown`。选择以稳定 `RowID` 表示，目标行在当前帧滚入可见区。该批准不扩展到编辑、多选、排序/过滤、横向滚动、Tab 焦点环或键盘激活事件。

## API 与兼容性

| 项目 | 已批准语义 | 兼容影响 |
|---|---|---|
| 开关 | `EnableKeyboardNav(DataGridKeyboardConfig{})` 显式开启；`DisableKeyboardNav()` 关闭；`KeyboardNavEnabled()` 查询 | 默认关闭；未调用新 API 的调用方按键不被消费，现有 `Clicked()` 语义不变 |
| 状态 | `Focused()` 仅用于诊断当前焦点 | 新增只读查询，不改变旧状态 |
| 索引 | 启用或 `SetRows` 成功时在既有 O(N) 校验遍历内建立 `RowID -> index` | 不把 O(N) 成本隐藏到 Layout 或按键帧；`UpdateReport` 披露建立结果 |
| 选择 | 键盘只更新选中 `RowID`，不伪造鼠标 `Clicked()` 或独立激活事件 | 调用方继续通过 `SelectedRowID()` 读取选择 |
| 关闭 | `DisableKeyboardNav` 停止注册过滤器并释放索引，保留选择状态 | 关闭后恢复基础组件按键语义 |

## 键位与边界

| 按键 | 无选择 | 有选择 |
|---|---|---|
| `Down` / `Up` | 选择当前可见首行 | 向下/向上移动一行并钳制 |
| `Home` / `End` | 选择首行/末行 | 跳到首行/末行 |
| `PageDown` / `PageUp` | 从可见首行按页移动并钳制 | 按页移动并钳制 |

- `PageRows > 0` 使用显式值；`PageRows <= 0` 使用当前可见行数，至少为 1。
- 仅消费 `key.Press`；平台连发由宿主表现为多个 `Press`，组件不自行节流。
- 空表不产生选择、不访问全表。
- 空 body（`bodyH <= 0`）可以更新 `RowID` 选择，但不滚动、不扩大访问窗口；视口恢复后由下一次导航将目标行滚入可见区。
- 重排、缩短或清空后以当前数据和稳定 `RowID` 为准；被删除的选择按既有 `SetRows` 语义清除。

## 焦点隔离

焦点采用两层防护：

1. 按键过滤器限定到当前 DataGrid 的 Gio focus 标签。
2. 仅在网格实际持焦时轮询命名过滤器；未持焦时不注册/不轮询，保持稳定帧零分配口径。

网格内任意位置（包括表头和空白带）的主键按压可以取得焦点，但不因此选择行。焦点转交给 `widget.Editor` 等消费者后，网格停止消费按键；不内建 Tab 焦点环，也不自动夺取焦点。调用方如需程序化聚焦，可使用 Gio 标准焦点命令。

## 成本与证据

R28-B 离屏证据在 10k/100k 行、相同视口下验证：默认关闭与启用空闲帧均为 0 B/op、0 allocs/op；Layout-only 规模比约 1.15x，万行保持 1ms 内。启用或更新索引的 O(N) 成本单独计量，不归入稳定帧。

证据包括默认关闭、焦点隔离、初始无选择、PageRows、空 body、重排/缩短/清空、双实例隔离、Editor 焦点隔离、真实指针/键盘离屏事件和可编译行为变异。

## 不在本 ADR 范围

编辑、多选、排序/过滤、横向滚动、Tab 焦点环、程序化聚焦包装、键盘激活事件、IME/组合输入、真实 DPI、ThemeRef/动态主题缓存，以及 GXML/CLI 接线均不在本次批准范围。

## 发布验收门槛

本 ADR 的语义批准不等于发布级验收完成。真实 Windows 键盘连发、键位映射、IME、DPI 缩放和标题栏生命周期仍需协调者组织原生验收；在这些项目完成前，不得将 DataGrid 键盘导航标记为“原生验收通过”。
