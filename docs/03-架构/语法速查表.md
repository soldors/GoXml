# GXML 语法速查表

> 本文件是**手册**，不是规范。语义冲突时以
> [`GXML语言规范.md`](GXML语言规范.md) 为准。
>
> 速查表只做检索与示例，不定义新语义、不重复规范的论证过程。

## 1. 文件骨架

```xml
<Goxml Version="1" ViewModel="demo.ViewModel">
  <Defs>
    <!-- 可选的组件定义，必须在 <Page> 之前 -->
  </Defs>
  <Page Route="/">
    <!-- 必选，至少一个渲染节点 -->
  </Page>
</Goxml>
```

| 规则 | 说明 |
|---|---|
| `Version` | 必填，v1 只接受 `"1"` |
| `ViewModel` | 可选。缺省 = 纯静态页面 |
| `<Defs>` | 可选，**必须**出现在 `<Page>` 之前 |
| `<Page>` | 必填，且必须包含至少一个渲染节点 |
| `Route` | 页面路由标识 |

### 1.1 `ViewModel` 的合法写法

```text
TypeExpr := Ident                  // 同包：AppState
          | PkgDir "." Ident       // 包内类型：demo.ViewModel
PkgDir   := Ident ("/" Ident)*     // 模块根相对路径
```

**最后一个 `.`** 是包路径与类型名的分界。

| 写法 | 是否合法 |
|---|---|
| `AppState` | ✅ 与 `.gxml` 同包 |
| `demo.ViewModel` | ✅ |
| `internal/models.User` | ✅ |
| `example.com/app.User` | ❌ 完整导入路径不支持 |
| `*demo.ViewModel` | ❌ 指针 |
| `demo.Box[T]` | ❌ 泛型 |
| `../x.User` | ❌ 路径穿越 |

## 2. 布局标签

| 标签 | 作用 | 主轴 | 交叉轴 |
|---|---|---|---|
| `<Page>` | 页面根 | 垂直 | 水平 |
| `<Column>` | 纵向排列 | 垂直 | 水平 |
| `<Row>` | 横向排列 | 水平 | 垂直 |
| `<Grid>` | 网格（需 `Columns`） | 行优先 | — |
| `<Spacer>` | 占位，**不得**有子节点 | — | — |
| `<Expanded>` | 占满剩余空间，**必须且只能**一个子节点 | — | — |

> `<Page>` 等价于一个没有 `Gap` / `Padding` 的 `<Column>`。

```xml
<Column Gap="12" Padding="16">
  <Text Value="标题"/>
  <Row Gap="8" Align="Center">
    <Text Value="姓名"/>
    <Expanded><Input Value="{User.Name}"/></Expanded>
  </Row>
</Column>
```

## 3. 布局属性

### 3.1 通用属性（全部标签）

| 属性 | 取值 | 示例 |
|---|---|---|
| `Padding` | 1、2 或 4 个非负 dp | `Padding="16"`、`Padding="8 16"`、`Padding="1 2 3 4"` |
| `Background` | `#RRGGBB` / `#RRGGBBAA` / `$Theme.Field` | `Background="#336699"` |
| `Width` | `Fill` 或非负 dp | `Width="Fill"`、`Width="120"` |
| `Height` | `Fill` 或非负 dp | 同上 |

`Padding` 的多值含义：

```text
Padding="10"        → 四边 10
Padding="10 20"     → 上下 10，左右 20
Padding="1 2 3 4"   → 上、右、下、左
```

### 3.2 容器属性（`Column` / `Row` / `Grid`）

| 属性 | 取值 | 说明 |
|---|---|---|
| `Gap` | 非负 dp | 相邻子节点间距（早期叫 `Spacing`） |
| `Align` | `Start` / `Center` / `End` / `Baseline` | 容器对**所有直接子项**的交叉轴对齐 |
| `Justify` | `Start` / `Center` / `End` / `SpaceBetween` / `SpaceAround` / `SpaceEvenly` | 主轴剩余空间分布 |

**默认值**（按标签不同）：

| 标签 | 默认 `Align` | 理由 |
|---|---|---|
| `<Row>` | `Center` | 一行元素类比一行文字，垂直居中自然 |
| `<Column>` / `<Grid>` | `Start` | 一列内容类比一页文档，左对齐自然 |

### 3.3 `Align` / `Justify` 的限制

| 情形 | 结果 |
|---|---|
| `<Row Align="Baseline">` | ✅ 允许 |
| `<Column Align="Baseline">` | ❌ `GXML-ATTR-003` |
| `<Grid Align="Baseline">` | ❌ `GXML-ATTR-003`（v1 不支持） |
| 子项级对齐覆盖（`AlignSelf`） | ❌ v1 **不提供**，用嵌套 `<Row>`/`<Column>` 表达 |

### 3.4 `Width="Fill"` 的真实含义

`Fill` **不是**「一定填满」，取决于轴向与约束：

| 情形 | 行为 |
|---|---|
| 主轴方向 | 转成 flex weight 1 |
| 交叉轴方向 | 填满父容器交叉轴上限；**无界时退化为自然尺寸** |
| 固定尺寸 | 始终 Exact，可能溢出，**不裁剪** |

### 3.5 尺寸与约束

| 规则 | 说明 |
|---|---|
| 单位 | 全部为 dp，不接受单位后缀 |
| 缺省 | 内容自然尺寸 |
| 无界判定 | 上限 ≥ `1 << 20` 视为无界 |
| 网格子项 | `<Grid>` 的直接子项**不得**设置 `Width`（`GXML-ATTR-003`） |

### 3.6 Grid 专属

| 属性 | 必填 | 说明 |
|---|---|---|
| `Columns` | ✅ | 列数或列宽定义 |
| `Gap` | | 双轴间距 |

禁止与限制：

| 情形 | 结果 |
|---|---|
| 无 `Columns` | `GXML-ATTR-003` |
| 无子节点 | `GXML-ATTR-003` |
| `Columns=""` | `GXML-ATTR-003` |
| 直接子项设 `Width` | `GXML-ATTR-003` |
| `Align="Baseline"` | `GXML-ATTR-003` |

## 4. 内置控件

| 标签 | 属性 | 事件 | 属性类型 |
|---|---|---|---|
| `<Text>` | `Value`（必填）、`Color` | — | string、color |
| `<Button>` | `Text`、`Enabled` | `Click` | string、bool |
| `<Input>` | `Value`、`Enabled` | `ValueChanged(value:string)` | string、bool |
| `<Image>` | `Src` | — | string |

```xml
<Text Value="你好"/>
<Button Text="保存" Enabled="{!IsSaving}" Click="Save"/>
<Input Value="{User.Name}" ValueChanged="OnNameChanged"/>
<Image Src="logo.png"/>
```

## 5. 绑定

### 5.1 语法

```text
{Path}        取值
{!Path}       取反（仅 bool）
Path := Identifier ("." Identifier)*
```

```xml
<Text Value="{User.Name}"/>
<If Condition="{!Dirty}"><Then>…</Then></If>
```

### 5.2 路径可以是什么

| 允许 | 示例 |
|---|---|
| ViewModel 字段 | `{User.Name}` |
| 零参单返回值方法（隐式取值） | `{Display}` → `Display() string` |
| `<For>` 循环变量 | `{item.Name}` |
| 指针字段（自动解引用） | `{Owner.Name}`（`Owner *User`） |
| 嵌入字段（提升） | `{Version}` |

| 禁止 | 说明 |
|---|---|
| 函数调用 `{F()}` | 写 `{F}`，且 F 必须零参单返回值 |
| 下标 `{Items[0]}` | v1 不支持 |
| Map 取值 `{M[k]}` | v1 不支持 |
| 算术/比较/三元/逻辑 | v1 不支持 |
| 任意 Go 代码 | 不支持 |

### 5.3 类型兼容

绑定值必须能赋给属性声明的类型。**不做隐式转换**。

| 绑定类型 | `string` | `bool` | `int` | `float` | `color` | `insets` |
|---|:--:|:--:|:--:|:--:|:--:|:--:|
| `string` | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| `bool` | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ |
| `int`（有符号） | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ |
| `uint`（无符号） | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ |
| `float32/64` | ❌ | ❌ | ❌ | ✅ | ❌ | ❌ |

- **命名类型按底层类别**：`type Status string` 兼容 `string`。
- **`color`** 只接受 `color.NRGBA` / `color.RGBA`（标准库）。
- **`insets`** 只接受 `contracts.EdgeInsets`。
- 结构相似的类型**不会**被接受（按精确类型身份判定）。

## 6. 控制流

### 6.1 `<If>`

```xml
<If Condition="{Dirty}">
  <Then><Text Value="有未保存修改"/></Then>
  <Else><Text Value="已保存"/></Else>
</If>
```

| 规则 | 说明 |
|---|---|
| `Condition` | 必填，必须是 bool 或 `{!bool}` |
| `<Then>` | 必填 |
| `<Else>` | 可选 |

### 6.2 `<For>`

```xml
<For Each="item" In="{Items}" Key="{item.ID}">
  <Text Value="{item.Name}"/>
</For>
```

| 属性 | 必填 | 说明 |
|---|---|---|
| `Each` | ✅ | 循环变量名 |
| `In` | ✅ | 可迭代对象（slice / array / map） |
| `Index` | | 索引变量名 |
| `Key` | 有状态子控件时必填 | 稳定标识，用于状态寻址 |
| `Virtualize` | | 虚拟化开关 |

| 规则 | 说明 |
|---|---|
| `In` 类型 | slice / array / map；**string 不可迭代**（`GXML-SCOPE-004`） |
| 循环变量作用域 | 仅在 `<For>` 子树内有效 |
| 嵌套 | 支持，内层可见外层变量 |
| `Key` | 子控件有状态时必须提供，否则状态会错位 |

## 7. 事件

```text
方法形参 = 事件声明参数（载荷） ++ 调用点实参
```

**顺序固定：载荷在前、实参在后。**

```xml
<!-- Input.ValueChanged 的载荷是 value:string -->
<Input Value="{User.Name}" ValueChanged="OnNameChanged"/>
<!-- → OnNameChanged(value string) -->

<!-- Click 无载荷，实参 1 个 -->
<Button Text="删除" Click="Delete(User.Age)"/>
<!-- → Delete(id int) -->

<!-- 载荷 + 实参组合 -->
<Input Value="{User.Name}" ValueChanged="OnOpen(User.Age)"/>
<!-- → OnOpen(value string, cardID int) -->
```

| 规则 | 诊断码 |
|---|---|
| 方法必须存在 | `GXML-EVENT-003` |
| 形参数量必须等于载荷+实参总数 | `GXML-EVENT-004` |
| 逐项类型必须兼容 | `GXML-EVENT-006` |
| 方法**不得**有返回值 | `GXML-EVENT-007` |
| 实参只能是字面量或点分路径 | `GXML-EVENT-005` |

实参字面量形式：

```text
'字符串'   单引号，保留引号作为类型标识
42         整数
2.5        浮点
true       布尔
User.Age   绑定路径
```

## 8. 组件定义 `<Def>`

```xml
<Defs>
  <Def Name="Field" Props="Label:string; Value:string" Events="Commit(value:string)">
    <Row Gap="12" Align="Center">
      <Text Value="{Label}" Width="72"/>
      <Input Value="{Value}" Width="Fill"/>
    </Row>
  </Def>
</Defs>

<Page Route="/">
  <Field Label="姓名" Value="{User.Name}"/>
</Page>
```

| 属性 | 说明 |
|---|---|
| `Name` | 必填，PascalCase；不能与内置控件同名（`GXML-DEF-002`） |
| `Props` | 属性声明，`名称:类型` 分号分隔；`=默认值` 可选 |
| `Events` | 事件声明，v1 仅做契约声明，**不传播** |

### 8.1 `<Slot/>`

```xml
<Def Name="Card" Props="Title:string">
  <Column>
    <Text Value="{Title}"/>
    <Slot/>
  </Column>
</Def>

<Card Title="提示"><Text Value="内容"/></Card>
```

| 规则 | 说明 |
|---|---|
| 替换内容 | 调用点子节点 |
| 子节点数量 | **最多一个**；多个报 `GXML-DEF-009` |
| 未声明 `<Slot/>` 却传子节点 | `GXML-DEF-009` |
| 递归引用 | `GXML-DEF-010` |

### 8.2 v1 限制：`<Def Events>` 不传播

Def 体内没有语法能「发出」事件，因此调用点的事件处理器签名**不会被校验**。
`Events` 只做契约声明与调用点名称校验，为后续版本保留。

## 9. 常见错误速查

| 写法 | 问题 | 诊断码 |
|---|---|---|
| `<Text/>` | `Value` 必填 | `GXML-ATTR-004` |
| `<Text Value="@Name"/>` | `@` 不是合法 XML 属性名字符 | XML 语法错误 |
| `<Button Clik="Save"/>` | 未知属性，**不会**退化为事件 | `GXML-ATTR-004` |
| `<Text Value="{Nope}"/>` | 首段无法解析 | `GXML-BIND-001` |
| `<Text Value="{User.Nmae}"/>` | 中间字段不存在 | `GXML-BIND-002` |
| `<Text Value="{User.note}"/>` | 字段未导出 | `GXML-BIND-003` |
| `<Text Value="{Count}"/>` | `int` 绑到 `string` 属性 | `GXML-BIND-004` |
| `<If Condition="{!Count}">` | 取反作用于非 bool | `GXML-BIND-004` |
| `<For Each="c" In="{Title}">` | string 不可迭代 | `GXML-SCOPE-004` |
| `<Column Align="Baseline">` | `Baseline` 仅 `Row` 支持 | `GXML-ATTR-003` |
| `<Grid>` 无 `Columns` | 必填缺失 | `GXML-ATTR-003` |
| `<Grid><Text Width="10"/></Grid>` | Grid 子项不得设 `Width` | `GXML-ATTR-003` |
| `<Button Click="NoSuch"/>` | 方法不存在 | `GXML-EVENT-003` |
| `<Button Click="OnWithReturn"/>` | 事件方法有返回值 | `GXML-EVENT-007` |

## 10. 诊断码前缀

| 前缀 | 含义 | 阶段 |
|---|---|---|
| `GXML-ROOT` | 文档结构与根节点 | Parser |
| `GXML-SYNTAX` | XML 语法 | Parser |
| `GXML-ATTR` | 属性名与用法 | Parser + Expander |
| `GXML-EVENT` | 事件语法与签名 | Expander + Analyzer |
| `GXML-DEF` | `<Def>` / `<Slot>` | Parser + Expander |
| `GXML-SCOPE` | `<If>` / `<For>` 与作用域 | Parser + Analyzer |
| `GXML-BIND` | 绑定路径与类型 | Analyzer |

完整清单见 [`诊断码目录.md`](诊断码目录.md)。
