## 核查 1：`BindingVal`

**位置**：`contracts/ir_schema.go`（`type BindingVal struct`）

### 定义

```go
type BindingVal struct {
    IsBinding bool     // true = 绑定路径；false = 静态字面量
    IsNegated bool     // 路径带 ! 前缀（仅布尔绑定允许）
    Raw       string   // 原始文本，用于诊断回显
    Segments  []string // 按 "." 切分后的路径分段
}
```

方法：

| 方法 | 行为 |
|---|---|
| `Path()` | 用 `.` 连接 Segments；静态值返回 `Raw` |
| `IsZero()` | `!IsBinding && Raw == "" && len(Segments) == 0` |

### 四态判定

| 能力 | 状态 |
|---|---|
| 静态/绑定二值区分 | ✅ **已实现** |
| 路径分段（构造期完成，不在运行时切分） | ✅ **已实现** |
| 取反标记 | ✅ **已实现** |
| 原始文本保留（诊断回显） | ✅ **已实现** |
| **携带类型信息** | ❌ **尚未实现**——`BindingVal` 无类型字段，类型由 Analyzer 解析后存入 `Facts` |

### 谁负责构造

`parser` 包（`internal/compiler/parser/attrs.go` 等）。Parser 只做**语法切分**，不做类型解析。

### 结构

type NodeFacts struct {

## 核查 4：Codegen — 是否消费 `Facts`、是否有绑定分支

**关键发现**：`internal/compiler/codegen/codegen.go` 中**唯一**出现 `IsBinding` 的地方是：

```go
func staticAttr(n *contracts.NodeIR, name string) (string, bool) {
    for _, a := range n.Attrs {
        if a.Name != name { continue }
        if a.Value.IsBinding {
            return "", false        // ← 绑定一律拒绝
        }
        return a.Value.Raw, true
    }
    return "", false
}
```

### 四态判定

| 能力 | 状态 |
|---|---|
| 消费 `Facts` | ❌ **尚未实现**——Codegen 只读 `DocumentIR`，从不读 `r.Facts` |
| 绑定代码生成分支 | ❌ **尚未实现**——绑定会被 `staticAttr` 拒绝，报「需要静态 Value」 |
| 使用 `ResolvedPath` | ❌ 尚未实现 |
| 生成缓存（静态子树） | ✅ 已实现（A4） |
| 生成 `<Column>` / `<Row>` | ✅ 已实现（B1） |

**这意味着**：契约 §11（类型兼容）和 Analyzer 的全部绑定能力，目前**没有任何 Codegen 消费方**。绑定信息解析出来了，但被丢弃。

## 核查 6：性能约束清单（不可违反）

| 约束 | 内容 |
|---|---|
| `INV-PERF-1` | 静态子树（无绑定/事件/条件/循环）必须 `op.Record` + `op.CallOp` 固化，稳定帧只回放 |
| `INV-PERF-4` | `<Text>` 绑定值未变化时**不得重建字符串、不得重新 shaping**；拼装文本必须在 ViewModel 侧或框架侧缓存，**禁止 Layout 内每帧 `fmt.Sprintf`**；稳定帧文本节点 `allocs/op == 0` |
| 契约 §16 | 静态缓存的所有权、失效、嵌套边界；`renderKey` 四项 |
| ADR-0001 | 零反射、静态子树固化、列表虚拟化 |

### 一个必须澄清的点

`INV-PERF-4` 的「不得重新 shaping」约束**当前无法验证**——它描述的是**绑定**场景，而绑定尚未实现。A1–A6 的静态树测试不覆盖它。
